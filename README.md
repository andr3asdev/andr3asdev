## 🦈 Featured Release: [Pet Shark — 3D Shark Live Wallpaper & Virtual Aquarium](https://petshark.app)

A real-time 3D shark live wallpaper and virtual pet simulator for Android built with **Three.js** and **Kotlin**.

* **Reactive Predator AI:** Real-time AI for sharks and schooling prey fish.
* **Double-Tap Feeding:** Tap to drop fish and trigger feeding frenzies.
* **Battery-Smart Engine:** Supports 45/60/120 FPS, day/night sync, and instant GPU pause.
* **Privacy First:** Zero ads, zero tracking, 100% offline.
